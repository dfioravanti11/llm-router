The stall is gone. What the router adds went from 40.17ms to 1.84ms, and the
interval around it contains zero, so this setup cannot tell it apart from
nothing. That agrees with the 1.20ms the mock has reported all along, and it is
the first time a real engine has agreed with it.

Read the deltas, not the arms. The direct arm's median moved from 3.63ms in run
03 to 30.46ms here, because the engine's cache state was different by this point
in the session. Comparing those two absolute figures would say the machine got
eight times slower. It did not. The controlled comparison is the difference
between two arms inside a single run, which is what the harness prints and what
gets published.

The p99 the spec asks for, under one millisecond, is still unresolved. That is
now three attempts, twice on a laptop and once here, and the reason has been the
same every time: the machine doing the measuring is also running everything being
measured.
