The fix was committed and pushed to GitHub. The machine running this had not
pulled it, so this is the same binary as 03, measured again.

The tell is in the second line of output. `Finished in 0.22s` is cargo saying it
had nothing to compile. A build that installs a change to the proxy's socket
setup takes a minute or two on eight cores.

The cause was an instruction that said the machine already had the code because
it had been pushed. Pushing to a remote does not update a clone. Six minutes of a
rented GPU went into re-measuring an unchanged binary, and the result reproduced
the previous one to within half a millisecond, which is exactly what an unchanged
binary should do.
